## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX

#### Что такое Markdown

Markdown — это лёгкий язык разметки для оформления текста с помощью простых символов (`#`, `*`, `-`). Он легко читается как в исходном виде, так и после рендеринга, и поддерживается большинством современных платформ.

#### Где применяется Markdown

Markdown используется в README-файлах на GitHub/GitFlic, в документации, блогах, форумах, мессенджерах, системах управления задачами и в статических сайтах.

#### Зачем Markdown нужен разработчикам

Markdown позволяет быстро писать и оформлять документацию, инструкции, комментарии и описания проектов, не отвлекаясь на сложные визуальные редакторы. Это экономит время и делает текст единообразным и читабельным.
