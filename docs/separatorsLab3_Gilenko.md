## Введение

Markdown — это простой язык разметки для быстрого форматирования текста (заголовки, списки, жирный/курсив). Легко преобразуется в HTML и используется для документации, постов в блогах и веб-контента.

---

## Основные возможности Markdown

Markdown поддерживает заголовки, списки, ссылки, выделение текста, таблицы, блоки кода. Синтаксис использует обычные символы вместо сложного кода, что делает его удобным и интуитивно понятным.

***

#### Заголовок 2
